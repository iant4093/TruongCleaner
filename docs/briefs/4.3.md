## Goal

Run the fixed cleanup commands that some rules delegate to (`xcrun simctl
delete unavailable`, `brew cleanup --prune=30`, `docker image prune -f`, …) with
the same strictness as the read-only runner, and report what they did.

## Requirements

REQ-CLEAN-07, REQ-SAFE-12, `safety.md` rule 14.

## API (`Sources/CleanerActions/OwnerCommand/`)

```swift
public struct OwnerCommandID: RawRepresentable, Hashable, Sendable, Codable { … }  // e.g. "simctl.deleteUnavailable"

public struct OwnerCommandDefinition: Sendable {
    public let id: OwnerCommandID
    public let candidates: [String]          // absolute executable paths, tried in order (e.g. /opt/homebrew/bin/brew, /usr/local/bin/brew)
    public let arguments: [String]           // fixed argv
    public let timeout: Duration
    public let preflight: Preflight          // see below
}
public enum Preflight: Sendable { case none, noBootedSimulator, dockerReachable, processNotRunning(String) }

public enum OwnerCommands {
    /// The complete allow-list. Nothing else can run.
    public static let all: [OwnerCommandID: OwnerCommandDefinition]
}

public struct OwnerCommandResult: Sendable, Codable {
    public let id: OwnerCommandID
    public let executable: String?
    public let exitCode: Int32?
    public let timedOut: Bool
    public let skipped: String?              // reason when not run (tool missing, preflight failed)
    public let outputTail: String            // last 4 KB of stdout+stderr, UTF-8 lossy
    public let duration: Duration
}

public struct OwnerCommandRunner: Sendable {
    public init()
    public func run(_ id: OwnerCommandID) async -> OwnerCommandResult
}
```

Allow-list (exact argv, executable candidates in order):

| ID | Executable candidates | argv | Timeout | Preflight |
|---|---|---|---|---|
| `simctl.deleteUnavailable` | `/usr/bin/xcrun` | `simctl delete unavailable` | 120 s | `noBootedSimulator` |
| `brew.cleanup` | `/opt/homebrew/bin/brew`, `/usr/local/bin/brew` | `cleanup --prune=30` | 300 s | `processNotRunning("brew")` |
| `pnpm.storePrune` | `/opt/homebrew/bin/pnpm`, `/usr/local/bin/pnpm` | `store prune` | 300 s | `processNotRunning("pnpm")` |
| `go.cleanCache` | `/opt/homebrew/bin/go`, `/usr/local/go/bin/go` | `clean -cache` | 300 s | `none` |
| `go.cleanModcache` | same | `clean -modcache` | 300 s | `none` |
| `docker.imagePrune` | `/usr/local/bin/docker`, `/opt/homebrew/bin/docker` | `image prune -f` | 300 s | `dockerReachable` |
| `docker.builderPrune` | same | `builder prune -f --filter until=168h` | 300 s | `dockerReachable` |

Per-device and per-runtime simulator deletion (`simctl delete <UDID>`,
`simctl runtime delete <id>`) take one argument each: add
`OwnerCommandRunner.deleteSimulator(udid:)` and `deleteSimulatorRuntime(identifier:)`
that validate the argument (`^[0-9A-F-]{36}$` for UDIDs; runtime identifiers
`^[A-Za-z0-9.-]{1,128}$`) and that the device/runtime currently exists via
`Simulators.devices()` / `runtimes()` (read-only, from CleanerScanner) and the
device is shut down. Anything else → skipped.

Runner rules (same as `ReadOnlyCommand`): `Process`, absolute path, argv array,
environment exactly `PATH=/usr/bin:/bin:/usr/sbin:/sbin:<dir of the executable>`,
`HOME`, `LANG=en_US.UTF-8`, plus `HOMEBREW_NO_AUTO_UPDATE=1`,
`HOMEBREW_NO_ANALYTICS=1` for brew, `DOCKER_CLI_HINTS=false` for docker; stdin
`/dev/null`; concurrent pipe reads; timeout = terminate, then kill after 5 s;
executable must exist, be a regular file or a symlink whose target is executable,
and not be world-writable. `docker` preflight: `docker info --format '{{.ServerVersion}}'`
with a 10 s timeout through the same runner (add it as an internal-only command).

   (app side only; another builder owns the gate). If the gate still refuses

   Install Update blocked while busy; implement
   `NSApplicationDelegate.applicationShouldTerminate` via

   ("A clean is still running") while busy. (Approved AppKit use.)

   that earlier cleans are included, in Smart Clean result sheet and Trash page.
   Kit side: `UndoService.freeSpaceNow` writes a `freeBegin` history line listing

   for this; another builder edits `Gate`/`Clean`).
4. **Updater rollback (safety.md #12, #13):** remove at the app path only after an
   EXDEV copy fallback and only if its bundle ID is ours; otherwise move aside;
   on failed rollback tell the user the hidden path. Stale `$TMPDIR` update
   folders: move to the Trash instead of `removeItem`.
5. **install.sh (release.md #3, #4, #5):** wrap the body in `main() { …; }` with

   (`.TruongCleaner.app.old`) so restore is a same-volume rename; quit politely by
   bundle ID (`osascript -e 'tell application id "com.iant4093.TruongCleaner" to quit'`

   run it; write it and test the other paths), then poll only the current user's
   processes (`pgrep -U "$(id -u)" -x TruongCleaner`) for 10 s and stop with a clear

   Re-run the install tests from brief 1.3 (fresh, upgrade, tampered, foreign
   bundle, truncated script `head -n 60 scripts/install.sh | sh` must change nothing)
   into `build/install-test*`.
6. **package.sh (release.md #7):** fail when `TRUONGCLEANER_BUILD_NUMBER` is set and
   differs from the built `CFBundleVersion`, or when version strings are empty.
7. **Version:** `MARKETING_VERSION = 1.0.0` in both configurations of

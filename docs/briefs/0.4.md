# Brief 0.4: Spike S4, volume and System Data numbers

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`,
`.kiro/steering/safety.md` and `.kiro/steering/tech.md` first.

## Goal

Find out which storage numbers a normal user process can read on macOS 27, so
the Overview and System Data pages can show them (REQ-SYS-01, -02, -03;
`docs/RULE_CATALOG.md` §4.10). Everything is read-only.

## What to build

SwiftPM package `spikes/s4-volume/` (tools 6.4, macOS 26, Swift 6 mode,
warnings as errors), executable `s4volume`. It prints one JSON document to
stdout and writes it to `spikes/s4-volume/out/volume-<timestamp>.json`.

Collect, each with the exact API used and any error:

1. For `/` and `/System/Volumes/Data`: `URLResourceValues` `volumeTotalCapacity`,
   `volumeAvailableCapacity`, `volumeAvailableCapacityForImportantUsage`,
   `volumeAvailableCapacityForOpportunisticUsage`, `volumeName`, `volumeUUIDString`,
   `volumeIsInternal`, `volumeSupportsFileCloning`.
2. `statfs`: `f_blocks`, `f_bfree`, `f_bavail`, `f_bsize`, `f_fstypename`, `f_mntfromname`.
3. `getattrlist` with `ATTR_VOL_SPACEUSED`, `ATTR_VOL_SPACEFREE`, `ATTR_VOL_SPACEAVAIL`
   (and `ATTR_VOL_INFO`). Report errno if unsupported.
4. Derived: purgeable = important − available; used = total − free (each way).
5. Snapshots: run `/usr/bin/tmutil listlocalsnapshots /` and
   `/usr/bin/tmutil listlocalsnapshotdates /` (absolute path, argv, env
   `PATH=/usr/bin:/bin`, 10 s timeout); parse names and dates; record exit code
   and stderr.
6. APFS container: `/usr/sbin/diskutil apfs list -plist` and `/usr/sbin/diskutil info -plist /`
   (same runner rules). Extract container capacity and free, and for each volume
   in the container: name, role(s), capacity in use.
7. `/usr/sbin/sysctl -n vm.swapusage` (or the `sysctlbyname` API).
8. Sizes readable without root: try `getattrlist`/`stat` on
   `/System/Volumes/Data/.Spotlight-V100`, `/System/Library/AssetsV2`,
   `/private/var/vm`, `/Library/Updates`, `/private/var/db/oah`. For each, record
   readable or the errno. For `/System/Library/AssetsV2` only, also total its
   allocated size with a simple read-only `FileManager.enumerator` walk capped at
   60 s (mark partial if capped).
9. `/usr/sbin/system_profiler SPStorageDataType -json` (timeout 60 s), raw
   capacity fields only.

Never run anything with `sudo`, and never run a command that changes state.
`tmutil` may only use `listlocalsnapshots` and `listlocalsnapshotdates`.

## Stop condition

Builds with zero warnings; one run's JSON saved in `out/`; a short
`spikes/s4-volume/out/summary.md` with a table: number, value (human readable),
API, readable as user (yes/no).

## Out of scope

`Packages/`, `src/`, UI, anything that writes outside `spikes/s4-volume/`.

## Report format

1. Files changed. 2. The summary table. 3. Every command run with exit code.
4. Deviations. 5. Open questions (for example, numbers that disagree with each other).

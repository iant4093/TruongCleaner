# Brief 4.1: System Data page

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`, every
file in `.kiro/steering/`, `docs/UI.md` §4.3, `docs/RULE_CATALOG.md` §4.10, and
the merged CleanerKit APIs (`Catalog.all` with the Info rules from task 4.2,
`Rule.sanctionedCommand`, `Rule.settingsURL`, `MatchSpec.computed`,
`ScanEngine`, `VolumeInfo`, `Snapshots`, `SwapProbe`, `Simulators`) first.

## Goal

The page that answers "what is System Data?": every contributor with its size
(or "Unknown"), what it is, whether it is safe, and the one action we offer.

## Requirements

REQ-SYS-01 … -05, REQ-UI-02, -05, -06.

## What to build (`src/TruongCleaner/Pages/SystemData/`)

- `SystemDataModel` (`@Observable @MainActor`): on appear (and Rescan), runs a
  `ScanRequest` with every Info rule that has roots (`.measureOnly`), resolves
  `.computed` keys itself — `purgeable` (VolumeInfo), `snapshots` (count + list;
  size "Unknown"), `swap` (SwapProbe), `rosetta` (no number, text only),
  `unexplained` (below) — and also shows read-only Developer contributors that
  belong here: simulator runtimes total (`Simulators.runtimes()` sizes), Docker
  disk image (`dev.dockerImage`).
- **Unexplained** = `VolumeInfo.dataVolumeUsed` − (sum of everything this page
  measured + the Overview's measured categories that are available in
  `AppModel`, if any). Never show a negative: clamp to 0 and say "Our
  measurements cover all used space" in that case. Explain it in one sentence
  (APFS clones and snapshots make sums imprecise; macOS does not report the
  breakdown).
- **Rows** (grouped `Form`): tile + name + size (or "Unknown" / "Needs Full Disk
  Access" / "macOS only") + a tier label ("Info") + one trailing action:
  - `settingsURL` → "Open Settings" (`NSWorkspace.shared.open`)
  - `sanctionedCommand` → "Copy Command" (pasteboard) with a popover showing the
    command and a one-line warning (e.g. "Needs your admin password. Run it in
    Terminal."). Never run it.
  - otherwise "Learn More" popover with the explain text.
- Header: total measured vs. used, and the Unexplained remainder, as a small
  stacked bar reusing `StorageBar`.
- Snapshots row expands (`DisclosureGroup`) to list snapshot dates.

Add only the needed `case` line in `RootView` and property in `AppModel`.

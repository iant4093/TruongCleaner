## Public API (in `Packages/CleanerKit/Sources/CleanerScanner/Walk/`)

```swift
public struct WalkOptions: Sendable {
    public var maxWorkers: Int            // clamp to 1...min(8, activeProcessorCount)
    public var totalsDepth: Int           // folder totals kept for depth 0...totalsDepth below root
    public var topFilesCount: Int         // size of the largest-files heap (0 = off)
    public var limit: Duration?           // stop and mark partial
    public var progressInterval: Duration // default .milliseconds(100)
}

public struct EntryID: Sendable, Hashable { public let fsid: UInt64; public let fileID: UInt64 }

public struct NodeTotal: Sendable {      // one per kept folder or file at depth <= totalsDepth
    public let url: URL
    public let depth: Int                 // 0 = root
    public let id: EntryID
    public let kind: Kind                 // .directory, .file, .symlink, .other
    public let flags: UInt32              // st_flags style (ATTR_CMN_FLAGS)
    public var allocatedBytes: Int64      // whole subtree
    public var privateBytes: Int64        // whole subtree, ATTR_CMNEXT_PRIVATESIZE (see below)
    public var fileCount: Int
    public var newestModification: Date?  // newest mtime anywhere in the subtree, including itself
}

public struct WalkResult: Sendable {
    public let root: URL
    public let nodes: [NodeTotal]         // depth-sorted, root first
    public let topFiles: [NodeTotal]      // largest by allocatedBytes, any depth
    public let files, directories, symlinks, hardLinkDuplicates, crossVolumeSkipped: Int
    public let deniedDirectories: [URL]   // capped at 500, plus deniedCount
    public let deniedCount: Int
    public let otherErrors: Int
    public let partial: Bool              // limit hit or cancelled
}

public struct WalkProgress: Sendable { public let files: Int; public let allocatedBytes: Int64; public let currentPath: URL? }

public enum BulkWalker {
    /// Walks `root` off the main actor. Calls `progress` at most once per interval.
    @concurrent public static func walk(
        _ root: URL, options: WalkOptions,
        progress: (@Sendable (WalkProgress) -> Void)? = nil
    ) async throws -> WalkResult
}
```

## Behavior

- `getattrlistbulk` with `ATTR_CMN_RETURNED_ATTRS | NAME | FSID | OBJTYPE | FILEID | FLAGS | MODTIME | ERROR`,
  `ATTR_FILE_LINKCOUNT | ATTR_FILE_ALLOCSIZE`, and `ATTR_CMNEXT_PRIVATESIZE` via
  `FSOPT_ATTR_CMN_EXTENDED`. If private size is not returned for an entry, use
  its allocated size as the private size and count it in a `privateSizeMissing`
  internal counter (expose it in `WalkResult`).
- Volume boundary: compare `ATTR_CMN_FSID` with the root's fsid (from
  `statfs`/`getattrlist` on the root). Never use `st_dev` alone (S1 finding 3).
- `openat(parentFD, name, O_RDONLY | O_DIRECTORY | O_NOFOLLOW | O_CLOEXEC)`; never
  follow symlinks; count them; they add no bytes.
- Hard links: files with link count > 1 count once per `EntryID` (a set shared by
  workers, behind a lock). Directory totals: a hard-linked file adds its bytes
  only the first time it is seen.
- Root that is itself a symlink or not a directory: throw `ScanError.notADirectory`.
- `EPERM`/`EACCES` on open → append to `deniedDirectories` (cap 500) and
  `deniedCount`; never 0-size silently.
- Workers: OS threads (S1 used `Thread` + a shared queue; keep that), bounded by
  `maxWorkers`; one reusable 256 KB buffer per worker; fds bounded; raise the
  soft fd limit if below 4,096 (restore not needed).
- Cancellation: `withTaskCancellationHandler` sets a stop flag; workers check it
  per directory batch; result returns within 100 ms with `partial = true`.
- Totals: per-node accumulation up to `totalsDepth` only (a parent-index chain
  for kept nodes; deeper entries add into their nearest kept ancestor). No
  object per file below that depth. Top-N heap for files.
- Progress: throttled with a monotonic clock; never call from more than one
  thread at a time.
- No `print`; `os.Logger` (subsystem `com.iant4093.TruongCleaner`, category
  `scanner`) for debug only, paths `privacy: .private`.

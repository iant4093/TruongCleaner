## Goal

Make five catalog rows work as `docs/RULE_CATALOG.md` intends, without making
any rule broader than the catalog.

## Changes

1. **Owners per root.** Add `owners: [OwnerSpec]` to `RootSpec` (default `[]`).
   The effective owners of a finding are `rule.guards.owners` **plus** the owners
   of the root the finding lies under. Update `browser.chromium` so each browser's
   roots carry only that browser's bundle ID, and `apps.electronCaches` so each
   app's roots carry only that app's ID; remove those IDs from the rule-level
   guards. The gate must compute the finding's root (deepest expanded root that
   contains it) and check rule + root owners. `GateContext.expandedRoots` stays
   `[URL]`; add `rootOwners: [URL: [OwnerSpec]]` to `GateContext` (default empty)
   and fill it wherever contexts are built in tests.
2. **Owner from a wildcard root segment.** Add `OwnerSpec.rootSegmentAsBundleID(index: Int)`:
   the bundle ID is the path component at `index` in the **expanded root** (e.g.
   for `~/Library/Containers/*/Data/Library/Caches`, the `*`). Same "looks like a
   bundle ID" rule as `childNameAsBundleID`. Implement it in the gate and in
   `ProcessNameOwnerProvider` (process lookup still `.unknown` for bundle IDs).
3. **Excluding by wildcard segment.** Add `Guards.excludeRootSegments: [String]`:
   glob patterns (single `*` allowed) matched against the `*` segments of the
   expanded root; a matching root is skipped entirely by the engine (count in
   `missingRoots`? no: add `excludedRoots: [URL]` to `RuleResult`). Then make
   `user.containerCaches` and `user.groupContainerCaches` real `.children` rules
   with `excludeRootSegments` = `com.apple.*`, `group.com.apple.*`, `*.com.apple.*`,
   `systemgroup.*` and owner `.rootSegmentAsBundleID` for container caches (group
   containers: no owner check possible, so tier **Review**, not Safe; record this
   change in the report).
4. **`.savedState` names.** `user.savedState` children are `<bundleID>.savedState`.
   Add `OwnerSpec.childNameAsBundleID(stripSuffix: String?)` (replace the
   no-argument case; update all uses) and use `".savedState"` for that rule.
5. **Permanent-only rules.** Add `Action.deletePermanently` and use it for
   `trash.user` and `trash.volumes`. The executor work in 3.3 treats it as
   permanent with confirmation; in this brief only the model, catalog and gate
   change (the gate allows it like `.trash`).
6. **Bundle check only for real bundles.** In the gate's `insideBundle` check,
   an ancestor or item counts as a bundle only if its extension is in the list
   **and** it is a directory that contains `Contents/Info.plist`, `Info.plist`
   (flat bundles) or `Contents/_CodeSignature`. A cache folder named
   `com.example.App` is no longer denied. Keep `.app` items allowed only with
   `allowWholeBundle`.

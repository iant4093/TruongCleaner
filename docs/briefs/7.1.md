# Brief 7.1: Onboarding, Overview recommendations, accessibility pass (tasks 7.1, 7.2)

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`, every
file in `.kiro/steering/`, `docs/UI.md` §4.1, §5, §6, and the merged app code in
`src/TruongCleaner/` first.

## Goal

First launch explains the app and offers Full Disk Access; the Overview shows
real recommendations; every page passes an accessibility review.

## Requirements

REQ-PERM-02, -03, REQ-UI-04, -05, -07, REQ-SYS-03.

## Part A: onboarding (`src/TruongCleaner/Pages/Onboarding/`)

- A sheet shown once (`@AppStorage("onboardingDone")`), also reachable from the
  Help menu ("Welcome to TruongCleaner"). Content, in plain words: what the app
  does; that cleaning moves items to the Trash and can be undone; that it never
  touches iCloud, Photos, Mail or Messages data; an optional Full Disk Access step
  with the deep link button, the `AppModel.access` state live, and "Skip for now";
  a note that after each update macOS may ask again (ad-hoc signing).
- Use a `TabView`-free paged layout (Back/Continue buttons), `PageHeader` style.

## Part B: Overview recommendations

Replace the placeholder row with real ones, without starting a scan by
themselves: if Smart Clean has results, "Smart Clean can free about X" (button
goes to Smart Clean); if the Developer rules' last results exist, the largest
developer item; if iOS backups were measured, their size; if snapshots exist,
their count with a link to System Data. If nothing has been scanned, one row
"Scan to see what can be freed" whose button starts the Smart Clean scan and
switches to that page.

Also wire REQ-PERM-03 for Smart Clean and System Data: when `AppModel.access`
changes from not granted/unknown to granted, those pages mark results as stale
and show "Full Disk Access changed — Scan again" (no automatic scan).

## Part C: accessibility pass (all pages)

- Every button, toggle and image has an accessibility label; sizes are spoken as
  "12.4 gigabytes" (reuse `SpokenSize`).
- Keyboard: ⌘R scans on Smart Clean, Developer, System Data, Space Lens, Large
  Files (toolbar button wired through `AppModel.toolbarScan` for each);
  ⌘⌫ cleans selected on Smart Clean; Space = Quick Look where lists show files.
- Reduce Transparency: every custom glass use (`glassEffect`, `.glass` button
  styles outside the toolbar) switches to opaque material. Increase Contrast:
  no information by color alone (tier labels have text).
- Reduce Motion: no animated transitions in Space Lens or the storage bar.
- Check both Light and Dark appearance by launching with
  `-AppleInterfaceStyle Dark` and taking a window screenshot of each page with
  `screencapture -l <windowID>` into `build/screens/` (find the window ID with a
  tiny Swift script using `CGWindowListCopyWindowInfo`). Look at them yourself and
  fix unreadable text, clipped labels at 760 pt width, or misaligned rows.

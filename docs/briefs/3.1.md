## Goal

The one door every deletion must pass. `SafetyGate.authorize` re-checks a
`Finding` against the file system and the outside world just before it is
acted on. This brief builds the gate and its providers; executors come in 3.3.

## API (`Packages/CleanerKit/Sources/CleanerActions/Gate/`)

```swift
public enum OwnerState: Sendable { case running, notRunning, unknown }
public protocol RunningAppsProvider: Sendable { func state(of owner: OwnerSpec, for item: URL) async -> OwnerState }
public protocol OpenFilesProvider: Sendable { func hasOpenFiles(under url: URL) async -> Bool? }   // nil = unknown

public enum DenyReason: Sendable, Codable, Hashable {
    case infoRule, userExcluded, outsideRoots, isRoot, protectedPath(ProtectedReason),
         symlinkAncestor, insideBundle, macOSProtected, changedSinceScan, missing,
         tooNew, unknownAge, keepNewest, ownerOpen(String), ownerUnknown,
         openFiles, openFilesUnknown, probeFailed(String)
    public var userMessage: String { get }   // plain words, e.g. "Slack is open"
}
public enum Verdict: Sendable { case allow, deny(DenyReason) }

public struct GateContext: Sendable {
    public var environment: Environment
    public var policy: PathPolicy
    public var expandedRoots: [URL]           // the rule's concrete roots (as scanned)
    public var runningApps: any RunningAppsProvider
    public var openFiles: any OpenFilesProvider
    public var allowWholeBundle: Bool         // true only for rule installers.macOS
}

public struct SafetyGate: Sendable {
    public init()
    public func authorize(_ finding: Finding, rule: Rule, context: GateContext) async -> Verdict
}
```

## Gate order (cheapest first; first failure wins)

1. `rule.tier == .info` or `rule.action == .none` → `infoRule`.
2. Standardize the URL. Resolve the **parent's** real path (`realpath` on the
   parent only; the item itself is never resolved) and rebuild the item URL.
3. User exclusion (via `policy.protectedReason` returning `.userExcluded`) → `userExcluded`.
4. Not inside any of `expandedRoots` (resolve each root's real path too) → `outsideRoots`.
5. `policy.isRoot` → `isRoot`.
6. `policy.protectedReason` → `protectedPath(reason)`.
7. Any ancestor between the root and the item is a symlink (`lstat` each
   component below the root) → `symlinkAncestor`.
8. Item or any ancestor below the root has a bundle extension (`app`, `framework`,
   `bundle`, `plugin`, `appex`, `kext`, `xpc`, `qlgenerator`, `prefPane`, `saver`,
   `mdimporter`, `driver`) → `insideBundle`, except when `allowWholeBundle` and the
   item itself is the `.app` (never something inside it).
9. `lstat` the item: missing → `missing`; flags `SF_RESTRICTED`, `SF_NOUNLINK`,
   `SF_IMMUTABLE`, `UF_IMMUTABLE`, `SF_APPEND`, `UF_APPEND` → `macOSProtected`.
   For directories, also check those flags on the item's parent (unlink needs the parent writable/unrestricted).
10. `(fsid, fileID)` from `getattrlist` (`ATTR_CMN_FSID | ATTR_CMN_FILEID`, `FSOPT_NOFOLLOW`) differs from the finding → `changedSinceScan`.
11. If the rule has `minAge`: recompute the newest modification inside the item
    with `BulkWalker` (`totalsDepth 0`, `maxWorkers 2`, 5 s limit). Partial or
    error → `unknownAge`; too new → `tooNew`.
12. Owners: for each `rule.guards.owners` ask `runningApps.state(of:for:)`.
    `.running` → `ownerOpen(name)`; `.unknown` → `ownerUnknown`.
13. `openFiles.hasOpenFiles(under:)`: `true` → `openFiles`; `nil` → `openFilesUnknown`.
14. `.allow`.

`keepNewest` is decided at scan time by the Matcher (the gate does not re-rank),
but the gate must deny a finding whose rule has `keepNewest` if the finding's
folder is now among the N newest of its parent (re-list the parent's children
modification dates with `getattrlistbulk`; error → `probeFailed`).

Any thrown error or unexpected errno in steps 2–13 → `probeFailed(detail)` (never allow).

## Providers (`Sources/CleanerActions/Liveness/`)

- `ProcessOpenFilesProvider`: uses `proc_listpidspath(PROC_ALL_PIDS, 0, path,
  PROC_LISTPIDSPATH_PATH_IS_VOLUME? no: use 0 for "under path" semantics per
  libproc.h, check the header`, buffer sized from a first call; excludes our own
  pid; returns nil if the call fails. If `libproc` is not importable from Swift
  via `Darwin`, add a module map only if it can be done without editing
  `Package.swift`; otherwise stop and say so in your report.
- `ProcessNameOwnerProvider`: `.processName(x)` → `proc_listallpids` + `proc_name`
  exact match; `.bundleID` and `.childNameAsBundleID` → `.unknown` (the app layer
  supplies a combined provider in task 3.4). `.childNameAsBundleID`: derive the
  bundle ID from the first path component of the item below its root; a name
  with fewer than 3 dot parts means "no owner" → `.notRunning`.
- `CompositeOwnerProvider(first:then:)`: returns the first non-`.unknown` answer
  in order; helps the app combine bundle and process providers.

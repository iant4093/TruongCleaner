## Ian's feedback (2026-11-09, screenshots in Dark mode)

1. Smart Clean / Developer rule rows: the disclosure chevron and the checkbox
   are slightly off. The chevron sits outside the row's left inset, its vertical
   center does not line up with the checkbox, and rows with and without a
   checkbox (Review rows, the "Docker disk image" Info row) start their text at
   different x positions. Sizes in Info rows are further right than in rule rows.
2. System Data rows are not clean or consistent: buttons have different widths
   and stack ("Open Settings" over "Copy Command"); the size and the "Info" badge
   are stacked and right-aligned at varying x; long explain text wraps under the
   trailing column; rows have one, two or zero buttons.

## Target layout (both pages, one shared component)

Create `Components/ItemRow/` with one row view used by all three pages:

```text
[▸] [☐] [tile]  Title                         [badge]  Size   [action ⋯]
                Explain text (secondary, ≤ 2 lines,
                full text in a help tooltip / popover)
```

- Fixed leading column widths so every row's title starts at the same x, whether
  or not it has a chevron, checkbox or tile (reserve the space; hide the content).
  Chevron and checkbox are vertically centered on the **title line**, not the row.
- The disclosure uses the system `DisclosureGroup` style chevron (rotate on
  expand, Reduce Motion respected), inside the form inset.
- Trailing column: one fixed-width size column (monospaced digits,
  `.monospacedDigit()`), right-aligned, the same x for every row; tier badge
  ("Review", "Info", "Needs access") as a small capsule to the left of the size,
  one style for all.
- Actions: at most one visible button per row. Rows with several actions
  (snapshots: Open Settings + Copy Command) show the main one as a button and the
  rest in a `Menu` with an `ellipsis` label; buttons use `.controlSize(.small)`
  and `.buttonStyle(.bordered)`, equal minimum width.
- Explain text uses `.lineLimit(2)` with `.help(fullText)`; the full text is
  also in the row's info popover.
- Row vertical padding uniform; dividers aligned to the title's leading edge, as
  System Settings does.
- Section headers in Smart Clean / Developer: the category checkbox aligned with
  the rows' checkbox column, the total aligned with the size column.
- Skipped-item messages that show bundle IDs (`ownerOpen` details like
  `com.apple.dt.Xcode`) show the app's name instead (look it up with
  `NSWorkspace.shared.urlForApplication(withBundleIdentifier:)` + the bundle's
  display name; fall back to the ID). History page too, read-only display change.

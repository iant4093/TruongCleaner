## Public API (`Packages/CleanerKit/Sources/CleanerScanner/System/`)

```swift
public struct ReadOnlyCommand: Sendable {
    /// Only these executable + argv pairs may run (exact match). Refused otherwise, without launching.
    public static let allowList: [String: [[String]]]
    public static func run(_ executable: String, _ arguments: [String], timeout: Duration) async -> CommandResult
}
public struct CommandResult: Sendable { exitCode, timedOut, launchError, stdout: Data, stderr: Data, duration }

public struct VolumeInfo: Sendable {
    public let total, available, availableForImportantUsage, availableForOpportunisticUsage: Int64
    public var purgeable: Int64 { max(0, availableForImportantUsage - available) }
    public let containerUsed: Int64          // total - available
    public let dataVolumeUsed: Int64?        // ATTR_VOL_SPACEUSED on /System/Volumes/Data
    public let volumes: [APFSVolumeUsage]    // from diskutil apfs list -plist (name, roles, bytesUsed)
    public static func current() async -> VolumeInfo      // never throws; missing parts nil/empty
}

public struct LocalSnapshot: Sendable, Hashable { public let name: String; public let date: Date?; public let isTimeMachine: Bool }
public enum Snapshots { public static func list() async -> Result<[LocalSnapshot], ProbeError> }

public struct SwapUsage: Sendable { total, used, free: Int64 }
public enum SwapProbe { public static func current() -> SwapUsage? }

public struct SimulatorDevice: Sendable { udid, name, runtimeID, state, isAvailable, dataPath: URL?, lastBootedAt: Date? }
public struct SimulatorRuntime: Sendable { identifier, name, version, sizeBytes: Int64?, lastUsedAt: Date?, isDeletable: Bool? }
public enum Simulators {
    public static func devices() async -> Result<[SimulatorDevice], ProbeError>
    public static func runtimes() async -> Result<[SimulatorRuntime], ProbeError>
}
```

Allow-list (exact):

| Executable | argv |
|---|---|
| `/usr/bin/tmutil` | `listlocalsnapshots /`, `listlocalsnapshotdates /` |
| `/usr/sbin/diskutil` | `apfs list -plist`, `info -plist /` |
| `/usr/bin/xcrun` | `simctl list devices --json`, `simctl runtime list --json` |

Runner rules: absolute path; `Process` with argv; environment exactly
`PATH=/usr/bin:/bin:/usr/sbin:/sbin`, `HOME`, `LANG=en_US.UTF-8`,
`DEVELOPER_DIR` only if set in the parent; stdin `/dev/null`; stdout/stderr read
concurrently (no pipe deadlock on large plist output); timeout terminates then
kills after 2 s. Missing `xcrun`/Xcode → `ProbeError.toolMissing`.

Parsing is pure and separately testable: `SnapshotParser.parse(listOutput:datesOutput:)`,
`APFSListParser.parse(plist: Data)`, `SimctlParser.devices(json:)`,
`SimctlParser.runtimes(json:)`. Unknown fields ignored; malformed input →
`ProbeError.parse` (never a crash). Snapshot names: `com.apple.TimeMachine.YYYY-MM-DD-HHMMSS.local`
(Time Machine) and any other name (third-party, `isTimeMachine = false`).

## Tests (`Tests/CleanerScannerTests/System/`)

- Parser tests on fixture strings checked into `Tests/CleanerScannerTests/System/Samples/`
  (write them by hand from Apple's documented formats; capture real
  `diskutil apfs list -plist` and `xcrun simctl list devices --json` / `runtime list --json`
  output from this Mac into samples, trimmed and with UDIDs/UUIDs replaced by fakes).
  Cases: zero snapshots (header only), 3 TM snapshots + 1 third-party, garbage input.
- `ReadOnlyCommand` refuses a non-listed argv without launching (check
  `launchError`), and refuses a relative executable path.
- `ReadOnlyCommand` timeout: allow-list cannot be changed by tests, so expose an
  `internal` runner used by both `run` and a test that runs `/bin/sleep 5` with a
  200 ms timeout and expects `timedOut` within 3 s.
- `VolumeInfo.current()` on this Mac: total > 0, available ≤ total, purgeable ≥ 0 (a live smoke test; allowed because it only reads).
- `SwapProbe.current()` non-nil.

Also add `tcbench volume` that prints `VolumeInfo`, snapshots, swap, and
simulator counts.

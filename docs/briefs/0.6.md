# Brief 0.6: Spike S2, Full Disk Access probe

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`,
`.kiro/steering/safety.md` and `.kiro/steering/tech.md` first.

## Goal

A tiny app Ian runs to learn which Full Disk Access checks work on macOS 27
(REQ-PERM-01, -02, -03). Ian toggles FDA for it in System Settings and reports
what the app shows. All probes are read-only.

## What to build

SwiftPM package `spikes/s2-fda/` (tools 6.4, macOS 26, Swift 6 mode, warnings
as errors), executable `S2FDA` with a SwiftUI `@main App`. Plus
`spikes/s2-fda/make-app.sh` that builds Release and wraps it into
`spikes/s2-fda/out/S2FDA.app` (bundle ID `com.iant4093.TruongCleaner.spike.s2`,
`LSMinimumSystemVersion` 26.0), ad-hoc signed.

The window is a grouped `Form` with:

1. A table of probes. For each: path, method, result (`readable`, `EPERM`,
   `EACCES`, `ENOENT`, other errno), time in ms. Probes, each tried with
   `opendir`+`readdir` of one entry (directories) or `open(O_RDONLY)` + read 1 byte (files):
   - `~/Library/Safari`
   - `~/Library/Safari/Bookmarks.plist`
   - `~/Library/Mail`
   - `~/Library/Messages`
   - `~/Library/Containers/com.apple.stocks`
   - `~/Library/Containers/com.apple.mail/Data/Library/Mail Downloads`
   - `~/Library/Application Support/MobileSync/Backup`
   - `~/.Trash`
   - `~/Library/Application Support/com.apple.TCC/TCC.db`
   - `/Library/Application Support/com.apple.TCC/TCC.db`
   - `/Library/Preferences/com.apple.TimeMachine.plist`
   - `~/Library/Containers` (list entries; count how many children are readable)
   - `~/Library/Group Containers` (same)
   - `~/Library/Application Support/Google/Chrome` and `~/Library/Application Support/discord` (only if they exist)
2. A combined verdict using this rule: `granted` if any of the Safari, Mail,
   Messages or Stocks probes is readable; `notGranted` if all that exist return
   `EPERM`/`EACCES`; else `unknown`.
3. Buttons: "Run Again", "Open Full Disk Access Settings" (opens
   `x-apple.systempreferences:com.apple.preference.security?Privacy_AllFiles`
   with `NSWorkspace.shared.open`; show whether `open` returned true),
   "Open Privacy & Security" (fallback
   `x-apple.systempreferences:com.apple.preference.security`), and "Copy Results"
   (copies a plain-text table to the pasteboard).
4. Re-run the probes automatically on `NSApplication.didBecomeActiveNotification`
   and show the time of the last run.

Probes run off the main actor. Never write, move or delete anything.

## Stop condition

`make-app.sh` produces `out/S2FDA.app` with zero warnings; `codesign --verify`
passes; the app launches (check with `pgrep` after `open -n`, then stop it with
`pkill -f S2FDA.app/Contents/MacOS/S2FDA`). Also add a `--cli` flag that runs the
probes once, prints the table to stdout and exits, and include that output from
your own run in the report (it shows what a non-FDA process sees).

# Brief 2.5: Overview page

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`, every
file in `.kiro/steering/`, `docs/UI.md` §1, §2, §4.1 and §6 first. Tasks 2.2
(`VolumeInfo`, `Snapshots`, `SwapProbe`) and 1.1 (app shell) are merged.

## Goal

The first real page: an Overview that shows the startup disk like System
Settings > Storage, with real numbers from CleanerKit, and placeholders where
later waves add category sizes.

## Requirements

REQ-SYS-01, REQ-SYS-02, REQ-UI-02, REQ-UI-05 (labels), REQ-UI-07, REQ-PERF-02.

## What to build (`src/TruongCleaner/`)

- `Pages/Overview/OverviewModel.swift`: `@Observable @MainActor final class`.
  `func refresh() async` loads `VolumeInfo.current()`, `Snapshots.list()` and
  `SwapProbe.current()` concurrently (the kit functions already run off the
  main actor; do not block the main actor). Holds `state: .loading / .loaded(OverviewData) / .failed(String)`.
  Refreshes on appear and when the app becomes active (at most once per 30 s).
  No timers.
- `Pages/Overview/OverviewPage.swift`:
  1. Header group (`PageHeader`): drive tile, volume name ("Macintosh HD" from
     `volumeName` or a fallback), subtitle "X of Y used · Z available" using
     `ByteFormatter`.
  2. Storage bar section: `Components/StorageBar.swift`, a Swift Charts
     horizontal stacked `BarMark` for: **Used by macOS volumes** (System +
     Preboot + Recovery + VM + Update, from `volumes`), **Data** (data volume
     used), **Purgeable**, **Free**. Legend below with dots and sizes. Use system
     colors only (`.gray`, `.blue`, `.orange`, `.secondary`). Later waves split
     "Data" into categories; design `StorageBar` to take an array of
     `(label, bytes, color)` segments.
  3. "Storage details" grouped section with `LabeledContent` rows: Purgeable,
     Local snapshots (count, "size unknown" note), Swap in use, Available for
     important data. Each row has an info button (`Image(systemName: "info.circle")`
     button) showing a popover with one or two plain sentences on what it means
     and where the number comes from (text in `docs/UI.md` style; plain words).
  4. "Recommendations" section: a single row "Run Smart Clean to see what can
     be freed" (button disabled until Wave 3), so the layout is final.
- Accessibility: the bar has an `accessibilityLabel` summarizing all segments;
  every info button has a label.
- `AppModel` gets an `overview: OverviewModel` property; `RootView` shows
  `OverviewPage` for `.overview` instead of the placeholder.

Use `Form { }.formStyle(.grouped)` for sections. No custom backgrounds, no glass on rows.

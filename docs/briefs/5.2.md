## Goal

A sunburst view of any folder the user picks, with drill-down, so they can see
what takes space. Read-only in this brief: no delete action yet.

## Requirements

REQ-UI-02, REQ-UI-05, REQ-PERF-07, REQ-SCAN-04 (denied folders shown).

## What to build (`src/TruongCleaner/Pages/SpaceLens/`)

- `SpaceLensModel` (`@Observable @MainActor`): `root: URL` (default home),
  `path: [URL]` breadcrumb, `state: idle | scanning(progress) | ready(LensTree) | failed`.
  `scan(_ url:)` runs `BulkWalker.walk(url, options: totalsDepth 3, topFilesCount 0, maxWorkers 8)`
  and builds a `LensTree` (nodes to depth 3, children sorted by allocated size,
  children beyond the 40 largest per node merged into one "Other" slice).
  Drilling into a child re-walks that child (results are cached per URL for the
  session; a "Rescan" button clears the cache). Cancel the previous walk when
  a new one starts.
- `SunburstView`: rings for depth 1–3 drawn with Swift Charts `SectorMark`
  (`innerRadius`/`outerRadius` per ring, `angle` = size) **or** a `Canvas`
  if Charts cannot do concentric rings cleanly. Pick one, explain in the report.
  Colors: hue per top-level child (system palette), lighter per depth. Hover
  shows name + size in a tooltip/overlay; click on a directory drills in; the
  center circle shows the current folder's name and total and goes up one level
  on click.
- Beside the chart (or below on narrow windows), a `List` of the current folder's
  children: icon (`NSWorkspace.shared.icon(forFile:)`, cached), name, size bar,
  size. Context menu: Reveal in Finder, Quick Look (`.quickLookPreview` binding).
  Denied folders show a lock symbol and "Needs access".
- Toolbar on this page: "Choose Folder…" (`NSOpenPanel`, directories only), the
  breadcrumb as a path control (`ForEach` of buttons separated by chevrons),
  Rescan.
- Show "about" and a footnote: sizes are space used on disk; files that share
  storage (APFS clones) are counted in each place.
- Reduce Motion: no animated transitions between levels.
- Performance: never more than ~3,000 drawn sectors (merge small slices < 0.5°
  into their parent's "Other").

`AppModel` gets `spaceLens: SpaceLensModel`; add **only** the `case .spaceLens`
line in `RootView`'s detail switch (other builders edit nearby lines).

## Goal

`ScanEngine` turns a list of `Rule`s into findings by expanding roots, walking
them with `BulkWalker`, converting walker nodes to `Candidate`s and running
`Matcher.evaluate`. This is what Smart Clean calls.

## Requirements

REQ-SCAN-01, -04, -05, -06, -08, -09, REQ-RULE-03, -04, REQ-SYS-04 (sizes for Info rules).

## API (`Sources/CleanerScanner/Engine/`; replace the placeholder `ScanEngine.swift`)

```swift
public struct ScanRequest: Sendable {
    public var rules: [Rule]
    public var environment: Environment
    public var userExclusions: [URL]
    public var maxConcurrentRoots: Int = 2      // roots walked at once
    public var workersPerRoot: Int = 4          // BulkWalker maxWorkers per root (total threads <= 8)
}

public struct RuleResult: Sendable {
    public let ruleID: String
    public let findings: [Finding]
    public let skippedCounts: [SkipReason: Int]
    public let measuredBytes: Int64             // Info rules: allocated size of the roots; others: sum of findings
    public let measuredPrivateBytes: Int64
    public let needsAccess: [URL]               // denied roots or folders (capped 50)
    public let missingRoots: [URL]              // roots that do not exist (not an error)
    public let partial: Bool
    public let duration: Duration
}

public enum ScanEvent: Sendable {
    case ruleStarted(String)
    case progress(files: Int, allocatedBytes: Int64)   // throttled, whole scan
    case ruleFinished(RuleResult)
    case finished(ScanReport)
}

public struct ScanReport: Sendable { public let results: [RuleResult]; public let partial: Bool; public let duration: Duration; public let duplicatesDropped: Int }

public actor ScanEngine {
    public init()
    /// Starts a scan. The stream finishes after `.finished`. Cancelling the consuming task cancels the walks.
    public func scan(_ request: ScanRequest) -> AsyncStream<ScanEvent>
}
```

## Behavior

1. For each rule, `RootExpansion.expand` each `RootSpec`. Resolve `*` segments
   by listing that directory level (no symlink following, skip non-directories,
   stay inside the parent; at most 2,000 matches per `*`; a denied listing goes
   to `needsAccess`). Roots that do not exist go to `missingRoots`.
2. Match kinds:
   - `.children`: walk with `totalsDepth = max(1, rule.depth)`; candidates are nodes at depth 1.
   - `.glob(pattern)`: walk with `totalsDepth = number of components in the pattern`; candidates are nodes whose path relative to the root matches the pattern (reuse `CleanerCore`'s `GlobPattern` if public; otherwise add a small matcher in the engine and say so).
   - `.files(extensions:)`: walk with `totalsDepth = rule.depth` and `topFilesCount = 0`; candidates are file nodes at depth 1...depth with a matching extension (case-insensitive).
   - `.measureOnly`: walk with `totalsDepth = 0`; no candidates; `measuredBytes` = root totals.
   - `.ownerCommand`: not walked; return an empty `RuleResult` (Wave 4 sizes these).
3. `siblingNames` for `requiresSibling`: from the kept nodes at the same depth
   with the same parent (they are all kept because totalsDepth ≥ depth).
4. Build `Candidate` from `NodeTotal` (all fields map 1:1; `itemCount = fileCount`).
5. Run `Matcher.evaluate` with one `PathPolicy(environment:userExclusions:)`
   per scan. `findings` = `.finding` outcomes; count `.skipped` by reason.
6. A path found by two rules is kept only for the first rule in request order;
   count drops in `duplicatesDropped`.
7. Concurrency: at most `maxConcurrentRoots` walks at once, each with
   `workersPerRoot` workers; clamp so that the product ≤ 8. Use a task group with
   a bounded number of child tasks; never one task per rule. All work is off the
   main actor.
8. Progress: one throttled stream of `.progress` (≤ 10/s) summing all walks.
9. Cancellation: when the consumer cancels (stream `onTermination`), cancel the
   group; finish with a `.finished` report marked `partial`. Return within 200 ms.

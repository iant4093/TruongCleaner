# Brief 4.6: Home-folder categories for Overview and System Data

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`, every
file in `.kiro/steering/`, `docs/UI.md` §4.1, §4.3, and the merged
`Pages/Overview/**`, `Pages/SystemData/**`, `CleanerScanner/Walk/**` and
`CleanerScanner/Engine/**` code first.

## Problem

On Ian's Mac, System Data shows "91.04 GB of 830.4 GB used is accounted for;
739.37 GB is unexplained" because nothing measures the user's own files (apps,
documents, caches, developer data). The Overview bar shows one big "Data"
segment. Apple's Storage pane splits these.

## Goal

A category breakdown measured by our own walker, shown in the Overview bar and
subtracted in System Data, so "Unexplained" is the real remainder.

## Requirements

REQ-SYS-01, REQ-SYS-03, REQ-PERF-04, REQ-SCAN-07.

## Kit (`Sources/CleanerScanner/Categories/`)

```swift
public enum StorageCategory: String, Sendable, CaseIterable { case applications, documents, downloads, desktop, pictures, movies, music, icloud, libraryCaches, libraryOther, developer, iosBackups, mail, messages, trash, otherHome, otherUsers }
public struct CategoryTotals: Sendable { public var bytes: [StorageCategory: Int64]; public var privateBytes: [StorageCategory: Int64]; public var needsAccess: [StorageCategory: Int]; public let partial: Bool; public let duration: Duration }
public enum CategoryScanner { @concurrent public static func measure(home: URL, progress: …) async -> CategoryTotals }
```

Roots: `/Applications` (+ `~/Applications`) → applications; `~/Documents`,
`~/Downloads`, `~/Desktop`, `~/Pictures`, `~/Movies`, `~/Music` → their
categories; `~/Library/Mobile Documents` → icloud (allocated only: evicted files
count 0, which is correct); `~/Library/Caches` → libraryCaches;
`~/Library/Developer` → developer; `~/Library/Application Support/MobileSync/Backup`
→ iosBackups; `~/Library/Mail` + Mail container → mail; `~/Library/Messages` →
messages; `~/.Trash` → trash; the rest of `~/Library` → libraryOther; the rest of
`~` → otherHome. Each root walked once with `totalsDepth 0` (no nodes kept);
nested roots excluded from their parent's total (walk the parent with
`pruneNames`/exclusion so nothing is counted twice, or subtract the child's total
— explain your choice). Bounded concurrency (≤ 8 walker threads total). Results
cached in memory with a timestamp; refresh at most every 10 minutes unless asked.

Tests on a fixture home: every category gets the right bytes; no double count of
nested roots; a denied folder increments `needsAccess` and is not 0-sized silently.

## App

- `OverviewModel`: after the volume numbers load, start `CategoryScanner.measure`
  in the background (cancellable, shows a small "Measuring…" note). Replace the
  "Data" segment with category segments (Applications, Documents & files [documents
  + downloads + desktop], Photos & media [pictures + movies + music], iCloud Drive,
  Developer, Caches, iOS backups, Mail & Messages, Trash, Other in your home, and
  "System Data" = data volume used − purgeable − sum of the above). Legend shows
  each with size.
- `SystemDataModel`: "Unexplained" = data volume used − purgeable − sum of
  CategoryTotals − sum of System Data rows that are **not** inside the home
  folder (avoid subtracting `~/Library/Caches` twice: Info rows under `~` are
  already in the category totals). Explain in the header: "Measured: X. Not
  measured by any app: Y."
- Use `AppModel` to share one `CategoryTotals` between both pages.

## Commands to run before finishing

SwiftPM's manifest sandbox cannot nest inside your sandbox, so always pass
`--disable-sandbox` to `swift` commands. For `xcodebuild`, if package
resolution fails for the same reason, add
`-IDEPackageSupportDisableManifestSandbox=YES` and note it in your report.

```bash
swift build --disable-sandbox --package-path Packages/CleanerKit --scratch-path build/swiftpm
swift test  --disable-sandbox --package-path Packages/CleanerKit --scratch-path build/swiftpm
xcodebuild -project TruongCleaner.xcodeproj -list
xcodebuild -project TruongCleaner.xcodeproj -scheme TruongCleaner -configuration Debug \
  -derivedDataPath build/DerivedData CODE_SIGNING_ALLOWED=NO build
xcodebuild -project TruongCleaner.xcodeproj -scheme TruongCleaner -configuration Release \
  -derivedDataPath build/ReleaseDerivedData CODE_SIGNING_ALLOWED=NO build
```

Then check the Release app: `lipo -archs` prints `arm64`; `vtool -show-build`
shows platform MACOS, minos 26.0; `otool -L` shows no non-system frameworks;
`du -sh` of the `.app`. Launch the Debug app with `open -n`, check with `pgrep`
after 3 s that it is alive, then `pkill` it.

# Brief 6.2: Applications page and App Uninstaller

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`, every
file in `.kiro/steering/` (**`safety.md`**), **`docs/UNINSTALLER.md` in full**,

## Goal

The Applications sidebar page: a list of installed apps with sizes, and an
uninstaller that removes an app and its leftovers exactly as `docs/UNINSTALLER.md`
says.

## Kit

- `Sources/CleanerScanner/Apps/AppInventory.swift`: lists `.app` bundles in
  `/Applications` and `~/Applications` (depth ≤ 2, no symlink following), reading
  Info.plist and signing info (Security framework). Result type says whether the
  inventory is complete; any failure → incomplete. Sizes via `BulkWalker`
  (`totalsDepth 0`), computed lazily per app, ≤ 6 threads total.
- `Sources/CleanerCore/Uninstall/LeftoverMatcher.swift`: the pure matching of
  `UNINSTALLER.md` §3 (input: app facts, inventory, directory listings with names
  and metadata-plist identifiers / launch-agent labels+programs; output: candidates
  with tier and evidence text). No file I/O here.
- `Sources/CleanerScanner/Apps/LeftoverFinder.swift`: lists the §2 folders
  (direct children only), reads container metadata plists and launch-agent plists
  (`PropertyListSerialization`, size-capped 256 KB), sizes candidates, and calls
  the matcher. Returns `Finding`s plus the synthetic `apps.uninstall` `Rule`
  (built by a factory in `CleanerCore/Uninstall/UninstallRule.swift`).
- Gate: `Rule.allowsWholeBundle` must be true for `apps.uninstall` as well as
  `installers.macOS` (tests updated). Refusal list of §1 enforced in the kit
  (`UninstallEligibility`), not only in the UI.

## App (`src/TruongCleaner/Pages/Applications/`)

- List (searchable by the sidebar search? no: its own `.searchable` field in the
  page): icon, name, version, size (fills in as measured), "Apple" / "Running"
  badges for refused apps (disabled rows with the reason).
- Selecting an app shows an inspector-style detail: header with icon and total,
  the app bundle row, leftovers grouped by folder (Safe checked, Review unchecked,
  each with its evidence text in secondary type), Info rows for `/Library` items.
- "Move to Trash" uses the shared row/checkbox components from the Smart Clean
  page and `Services.makeCleaner` with the app-aware owner provider; confirmation
  names the app and total; result sheet notes LaunchAgents stay loaded until
  logout. Never offer permanent delete here.
- Accept a dropped `.app` (`.dropDestination(for: URL.self)`) to select it.
- Wire ⌘R (rescan inventory) through `AppModel.toolbarScan`.

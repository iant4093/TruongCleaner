## Encoding notes

- Owner-command rules (`dev.simUnavailable`, `dev.homebrew`, `dev.pnpm`,
  `dev.go`, `dev.goModules`, `dev.dockerDangling`): `match: .ownerCommand(spec)`
  and `action: .ownerCommand(spec)`, where `spec` names the matching
  `OwnerCommandID` from `OwnerCommands.all`. `OwnerCommandSpec` currently holds
  an executable URL + argv; if it cannot reference an ID, add
  `OwnerCommandSpec.id: String` (CleanerCore cannot import CleanerActions) and a
  catalog test asserting every owner-command rule's ID exists in
  `OwnerCommands.all` (that test lives in `Tests/CleanerActionsTests/`, which can
  import both).
- `dev.simDevices`, `dev.simRuntimes`: tier Review, `.ownerCommand` with IDs
  `simctl.deleteDevice` / `simctl.deleteRuntime` (per-item commands; the UI in
  4.5 lists devices/runtimes from `Simulators`). Add those two IDs to the
  catalog test's expectation list but **not** to `OwnerCommands.all` (they are
  the runner's per-item functions); document this.
- `dev.projectArtifacts`: tier Review, roots come from user-chosen folders.
  Model: add `RootSpec.Base.userChosen` (expanded from a list in `Environment`,
  add `projectFolders: [URL]` to `Environment`, default empty). Match: `.glob`
  patterns for each artifact name at any depth up to 6, `minAge` 30 days,
  `requiresSibling` per artifact as the catalog says (`target` → `Cargo.toml`,
  `build` → one of `build.gradle`, `build.gradle.kts`, `CMakeLists.txt`,
  `package.json`, `Makefile`), never at the root itself, and never under
  `~/Library/CloudStorage` or `~/Library/Mobile Documents` (already protected).
  "Skip if git-tracked" cannot be checked without running git: encode it as an
  `excludeNames`-style guard that skips any artifact whose parent contains a
  `.git` *file or folder* only when the artifact itself is tracked is not
  knowable here; so instead **skip artifacts that contain a `.git` entry**
  (nested repos) and document the gap.
- `dev.xcodeDeviceSupport`: `keepNewest 2` per platform folder (each platform
  folder is its own root).
- `dev.xcodeArchives`: Review; `.glob("*/*.xcarchive")` (date folders).
- `mail.downloads`: owner Mail (`com.apple.mail`), `minAge` 30 d. The "not
  modified after creation" check needs creation dates, which the walker does not
  collect: encode the age guard only and list the gap.
- `ios.backups`: Review, `.children`, access `fda`, never selected by default.
- `installers.macOS`: Review, root `/Applications`, `.glob("Install macOS*.app")`,
  `minAge` 14 d; the gate's `allowWholeBundle` must be true for this rule only
  (add a `Rule.allowsWholeBundle` computed property keyed by ID, or a guard flag,
  and a test that only this rule has it).
- All §4.10 rows: tier Info, `.measureOnly` where a path exists, action `.none`.
  Rows without a path (`system.purgeable`, `system.snapshots`, `system.swap`,
  `system.rosetta`, `system.unexplained`) need a root-less Info rule: add
  `MatchSpec.computed(String)` (a key the System Data page resolves), with
  `roots: []`. Well-formedness test: `.computed` only with tier Info.
- Each Info rule's `explain` names the sanctioned action from the catalog's
  last column; add `Rule.sanctionedCommand: String?` (exact command text for
  "Copy Command") and `Rule.settingsURL: URL?` where the catalog names a
  Settings pane. Fill them from §4.10 and for `logs.system`, `mail.store`,
  `mail.messagesAttachments`, `dev.dockerImage`.

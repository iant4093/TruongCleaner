# Brief 7.3: App icon and README screenshots

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`, every
file in `.kiro/steering/`, `docs/UI.md` §7, and look at TruongCam's README
screenshots section (`/Users/iantruong/Desktop/Fun/TruongCam/README.md`) for the
format.

## Goal

A native-looking app icon that supports macOS 26/27 icon styles, and a set of
compressed window screenshots for the README.

## Part A: icon

1. Preferred: an Icon Composer document `src/TruongCleaner/Resources/AppIcon.icon`
   (a folder with `icon.json` and layer assets) referenced by the target
   (`ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`). Find the `icon.json` schema
   by inspecting any `.icon` document that ships with Xcode 27 or its templates
   (`find /Applications/Xcode.app -name '*.icon' -maxdepth 8 | head`); build ours
   with two layers: a background (system-blue gradient) and a foreground glyph (a
   white internal-drive shape with a small sparkle, as SVG). Verify with
   `xcrun actool` (or the Debug build) that the compiled app has an icon
   (`Contents/Resources/AppIcon.icns` or `Assets.car` with `AppIcon`, and
   `CFBundleIconName` in Info.plist).
2. Fallback if (1) cannot compile: fill `Assets.xcassets/AppIcon.appiconset`
   with PNGs at all macOS sizes (16–1024 @1x/@2x), rendered by a small Swift
   script in `scripts/render-icon.swift` (Core Graphics: continuous-corner
   squircle per Apple's macOS icon grid, gradient, glyph drawn with SF Symbol
   `internaldrive.fill` via `NSImage(systemSymbolName:)` + `sparkles`). Explain
   in the report which path you took.
3. Put a 256 px PNG of the icon at `docs/screenshots/icon.png` for the README header.

## Part B: screenshots

Launch the Release build at a 1100 × 720 window in Light mode, open each page
(Overview, Smart Clean results after a **scan only**, System Data, Developer,
Space Lens of `~/Library/Developer` or another non-personal folder, Settings),
and capture the window with `screencapture -o -l <windowID>` (find the window ID
with a small Swift script using `CGWindowListCopyWindowInfo`). Drive page
selection with a launch argument you add: `-TCStartPage <page>` read in
`TruongCleanerApp` (Debug and Release; harmless) and `-TCAutoScan YES` to start
the page's scan on appear (scan only, never clean).

**Privacy:** do not capture file names from Downloads, Documents, Desktop, Mail
or Messages. If a list shows personal file names, crop or choose a different
folder. Prefer Developer and Library folders.

Convert to WebP (`sips -s format webp` if supported, otherwise `cwebp` is not
installed and you should use high-quality JPEG via `sips -s format jpeg -s
formatOptions 80`) into `docs/screenshots/`: `overview`, `smartclean`,
`systemdata`, `developer`, `spacelens`, `settings`. Each under 400 KB.

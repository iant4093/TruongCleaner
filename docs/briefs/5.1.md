# Brief 5.1: Large & Old Files page (read-only)

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`, every
file in `.kiro/steering/`, `docs/UI.md` §1, §4.5, §6, and the merged
`Sources/CleanerScanner/Walk/` API first.

## Goal

Find big files the user has not touched in a while, in folders they choose, and
let them review them. Read-only in this brief (Reveal in Finder, Quick Look);
moving to the Trash comes later through the safety gate.

## Requirements

REQ-UI-02, REQ-UI-05, REQ-SCAN-04.

## Kit addition (allowed, small)

`BulkWalker` already keeps a largest-files heap. Add in
`Sources/CleanerScanner/LargeFiles/LargeFileFinder.swift` (new file, do not edit
`Walk/`):

```swift
public struct LargeFileQuery: Sendable { public var roots: [URL]; public var minBytes: Int64; public var notModifiedSince: Date?; public var limit: Int }
public struct LargeFile: Sendable, Identifiable { id: EntryID; url; allocatedBytes; privateBytes; modified: Date? }
public enum LargeFileFinder { @concurrent public static func find(_ q: LargeFileQuery, progress: …) async throws -> [LargeFile] }
```

Implementation: walk each root with `topFilesCount = max(limit * 4, 500)`,
filter by `minBytes` and modification date, de-duplicate by `EntryID`, sort by
size, cap at `limit`. Tests in `Tests/CleanerScannerTests/LargeFiles/` on a
fixture (sizes, dates, hard-link duplicate, two roots overlapping).

Note: "last opened" is not available from `getattrlistbulk` without extra
cost; use modification date and label the column "Modified".

## UI (`src/TruongCleaner/Pages/LargeFiles/`)

- Controls row in a grouped section: folders list (default `~/Downloads`,
  `~/Documents`, `~/Desktop`, `~/Movies`; + / − with `NSOpenPanel`), minimum size
  `Picker` (50 MB, 100 MB, 500 MB, 1 GB; default 100 MB), "Not modified in"
  `Picker` (any time, 30 days, 90 days, 1 year; default 90 days), Find button.
- Results: SwiftUI `Table` with sortable columns Name (with file icon), Kind
  (`UTType` description), Size, Modified, Location (parent path, abbreviated
  with `~`). Multiple selection; nothing selected by default. Space bar = Quick
  Look of the selection; context menu: Reveal in Finder, Quick Look, Copy Path.
- Footer: count and total size of results, "about".
- Folder choices persist (`@AppStorage` with JSON-encoded paths or bookmarks;
  plain paths are fine because the app is not sandboxed).

`AppModel` gets `largeFiles: LargeFilesModel`; add **only** the
`case .largeFiles` line in `RootView`'s detail switch.

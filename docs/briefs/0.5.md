# Brief 0.5: Spike S5, System Settings look prototype

You are builder-sonnet. Implement exactly this brief. Read `AGENTS.md`,
`.kiro/steering/tech.md` and `docs/UI.md` first.

## Goal

A throwaway SwiftUI app that shows whether our components look like macOS 27
System Settings with Liquid Glass (REQ-UI-01, -02, -03, -04). Ian opens it and
compares it with System Settings by eye. Static fake data only.

## What to build

SwiftPM package `spikes/s5-ui/` (tools 6.4, macOS 26, Swift 6 mode, warnings as
errors), executable target `S5UI` with a SwiftUI `@main App`. Plus
`spikes/s5-ui/make-app.sh` that builds Release and wraps the binary into
`spikes/s5-ui/out/S5UI.app` (minimal `Info.plist`: bundle ID
`com.iant4093.TruongCleaner.spike.s5`, `LSMinimumSystemVersion` 26.0,
`NSPrincipalClass` NSApplication), then ad-hoc signs it (`codesign --force --sign -`).

Window content, following `docs/UI.md`:

1. `NavigationSplitView` with the full sidebar from `docs/UI.md` §3 (sections,
   rows, SF Symbols, tile colors), `.searchable(placement: .sidebar)`, and size
   badges with fake values.
2. `IconTile` as specified in `docs/UI.md` §3.1, plus a `PrototypeTuning` struct
   holding tile size, corner radius and symbol size so values are easy to change.
3. **Overview** page per `docs/UI.md` §4.1: header group (64 pt tile, title,
   subtitle), a stacked storage bar with Swift Charts `BarMark` and a legend,
   Recommendations section, Storage details with `(i)` popovers.
4. **Smart Clean** page per §4.2 (results state): sections with checkbox rows,
   explain text, sizes, one Review row unchecked, one Info row with no checkbox,
   and the floating clean bar in a `GlassEffectContainer` with a
   `.buttonStyle(.glassProminent)` "Clean" button.
5. **System Data** page per §4.3 with trailing action buttons.
6. Toolbar: a Scan button with `.glassProminent`, and a `ToolbarSpacer`.
7. When `accessibilityReduceTransparency` is on, the clean bar uses an opaque
   material instead of glass.
8. A Settings scene (⌘,) with one grouped form, to compare with the system's.

Every SF Symbol used must exist in SF Symbols 7 (macOS 26). Use
`if #available(macOS 27, *)` for anything newer, or avoid it.

## Stop condition

`make-app.sh` produces `out/S5UI.app` with zero warnings; `codesign --verify`
passes on it; `open -n spikes/s5-ui/out/S5UI.app` launches it without crashing
(check that the process is alive after 3 seconds with `pgrep -f S5UI`, then stop
it with `pkill -f S5UI.app/Contents/MacOS/S5UI`; `osascript` is blocked by the
safety hook, so do not use it).

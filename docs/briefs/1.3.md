## Scripts

All `#!/usr/bin/env bash`, `set -euo pipefail` (or `-uo` with explicit status
handling like TruongCam's `build.sh`), shellcheck-clean, run from any cwd (cd to
the repo root first), logs under `build/logs/`.

| Script | Behavior |
|---|---|
| `lint.sh` | Pinned SwiftLint 0.65.1 portable zip with the same SHA-256 check as TruongCam's `lint.sh`, cached under `build/tools/`; `swiftlint lint --strict --config .swiftlint.yml`. |
| `check-workflows.sh` | Same as TruongCam's (actionlint 1.7.12, zizmor 1.31.1, Gitleaks 8.30.1, same checksums), but `shellcheck scripts/*.sh scripts/hooks/*.sh`. Runs on ubuntu in CI; it must also work on macOS when the tools exist (pick the darwin_arm64 archives and their checksums from the same releases when `uname` is Darwin; fetch the real checksums from the releases' checksum files and pin them). |
| `test.sh` | `test.sh package` (default): `swift test --disable-sandbox --package-path Packages/CleanerKit --scratch-path build/swiftpm --parallel`, output tee'd to `build/logs/test-package.log`; fail on any test failure or warning. `test.sh list` lists tests. |
| `build.sh` | Modes `debug`, `release`, `all` (default `all`). `xcodebuild -project TruongCleaner.xcodeproj -scheme TruongCleaner -configuration <C> -destination 'generic/platform=macOS' -derivedDataPath build/<C>DerivedData CODE_SIGNING_ALLOWED=NO build`. Honors `TRUONGCLEANER_BUILD_NUMBER` (digits only) as `CURRENT_PROJECT_VERSION`. Prints toolchain first, PASS/FAIL per config with the first 40 unique `error:` lines, app path and size. Fails if the log has any `warning:` line from our sources. `TC_XCODEBUILD_FLAGS` (split on spaces) adds extra arguments; empty by default. Inside the agent sandbox you must run with `TC_XCODEBUILD_FLAGS=OTHER_SWIFT_FLAGS=-disable-sandbox` (macro plugins fail otherwise; see `docs/EVIDENCE.md` "Agent sandbox note"); CI does not set it. A "source warning" is a line matching `\.swift:[0-9]+:[0-9]+: warning:`; tool notices like `appintentsmetadataprocessor … warning:` do not count. |
| `package.sh` | From `build/ReleaseDerivedData/Build/Products/Release/TruongCleaner.app`: copy to `build/package/`, ad-hoc sign inside-out (`codesign --force --sign - --timestamp=none`, nested code first, no `--deep`), then verify: `codesign --verify --strict --verbose=2`, `lipo -archs` is exactly `arm64`, `vtool -show-build` platform MACOS and minos 26.0, `otool -L` lists only `/System/` and `/usr/lib/` libraries, no `Contents/Frameworks` except Swift-free system ones (none expected), dSYM UUID matches the binary (`dwarfdump --uuid`). Then create in `dist/`: `TruongCleaner.zip` (`ditto -c -k --keepParent`), `TruongCleaner.dmg` (`hdiutil create -volname TruongCleaner -srcfolder <stage with app + /Applications symlink> -format UDZO -ov`), `TruongCleaner.dSYM.zip`, a copy of `scripts/install.sh`, and `SHA256SUMS` (`shasum -a 256` of the four, in that order). Print sizes and hashes. Write `build/package/PACKAGING.txt` like TruongCam's. |
| `install.sh` | The user-facing installer (served from each release). POSIX `sh`, not bash. Steps: require macOS 26+ and arm64 (clear message otherwise); download `TruongCleaner.zip` and `SHA256SUMS` from `${TC_RELEASE_BASE:-https://github.com/iant4093/TruongCleaner/releases/latest/download}` with `curl -fsSL` into a `mktemp -d` folder; verify the ZIP line of `SHA256SUMS` with `shasum -a 256 -c`; stop on mismatch; unzip with `ditto -x -k`; choose `${TC_INSTALL_DIR:-/Applications}` if writable else `~/Applications`; if TruongCleaner is running, ask it to quit (`pkill -x TruongCleaner`, wait up to 5 s); replace the old bundle by moving it into the temp folder first, then moving the new one in (so a failure leaves something usable); `codesign --verify` the installed app; `open` it unless `TC_NO_OPEN=1`; print the uninstall line. Never use `sudo`. Clean up the temp folder with a `trap`. The only path it may remove is `<install dir>/TruongCleaner.app` (after checking its `CFBundleIdentifier` is `com.iant4093.TruongCleaner`) and its own temp folder. |
| `check-deletion-sites.sh` | Fails if any Swift file under `src/` or `Packages/CleanerKit/Sources/` other than `Packages/CleanerKit/Sources/CleanerActions/` contains `removeItem(`, `trashItem(`, `recycle(`, `unlink(`, `unlinkat(`, `rmdir(`, `remove(` as a C call, `"rm"`, `"/bin/rm"`, or `Process` launching anything (check `Process(`, `executableURL`) outside `CleanerScanner/ReadOnlyCommand*.swift` and `CleanerActions/`. Print each hit with file:line. Exit 0 with "PASS" otherwise. Include a self-test mode `--self-test` that runs the matcher on a temporary fixture under `build/` with one allowed and one forbidden file. |
| `clean.sh` | Removes `build/` and `dist/` in the repo only (resolve the repo root and check both paths are inside it before removing). |

## Findings from screenshots (Dark, 900 × 620 window)

1. **System Data: empty gap.** Every System Data row reserves the chevron and
   checkbox columns although no row there has either, so the icons start ~90 pt
   in from the section edge. Fix: a section (or `Form`) declares which leading
   columns it uses (`.itemRowLeadingColumns([.tile])` or similar); columns are
   reserved only if the section uses them. Smart Clean and Developer keep
   chevron + checkbox + tile.
2. **Smart Clean: the "Needs Full Disk Access" footer is cramped.** It wraps to
   "Needs Full / Disk Access" in a narrow column, the button floats mid-row, and
   the explanation sits under it. Fix: the footer is one line aligned with the
   title column: lock symbol + "Some folders need Full Disk Access" (secondary),
   and the "Open Privacy Settings" button in the row's action column (same x as
   other row actions). The longer explanation goes into `.help`.
   Show at most one such footer per **section** (under the section's last row)
   when several rows in it need access, listing nothing else.
3. **Applications: Script Editor applets labeled "Apple app".** Bundles whose ID
   starts with `com.apple.ScriptEditor.id.` or `com.apple.Automator.` and that are
   **not** Apple-signed (ad-hoc or Developer ID) are user-made applets. Allow
   uninstalling them, but only with exact bundle-ID evidence (no name-only
   matches, no prefix matches beyond `<bundleID>.`). Label otherwise-refused
   Apple apps "Made by Apple"; add tests for both.
4. **Applications: "Needs an administrator" text.** Make the reason say why:
   "Owned by another user (installed by an installer)" when the owner differs,
   "Can't change the Applications folder" when the parent is not writable.
   Keep the refusal logic (moving a folder to another parent needs write access
   to the folder itself, so root-owned bundles really cannot be moved).
5. **Applications list:** add a sort picker (Name, Size) and show the total of
   the app bundle and leftovers in the detail header before any action.

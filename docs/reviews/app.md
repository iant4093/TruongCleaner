## Checked and found correct

- **Clean confirmations.** ⌘⌫ (`CleanBar`, Smart Clean and Developer only) only sets `showConfirm`, so a dialog always opens first. `SmartCleanModel.clean` returns early for `.permanent` without `permanentConfirmed`, and only the second dialog's button passes `true`. Trash Empty uses two chained dialogs (`emptyFirst` → `emptySecond`), and the binding does not undo the step change. The uninstall is always `.trash`. Developer commands, simulator delete and runtime delete each need a destructive confirmation that shows the exact argv. No `onDeleteCommand` or other destructive shortcut exists.
- **Double-click and overlap guards.** Every start sets its busy state synchronously before the first `await`: Smart Clean `.cleaning(nil)`, Applications `cleanState`, Trash `activity`, History `isPuttingBack`, `isWorking`, `DeveloperModel.running`. Scanning cannot start while cleaning (`canScan`, `isBusy`). The Applications toolbar is disabled while uninstalling, and `reload`/`select` refuse to run while `isCleaning`. Result sheets disable Done and interactive dismiss while `isWorking`.
- **Debug launch arguments.** `-TCStartPage`, `-TCAutoScan`, `-TCLensRoot` and `-TCWindowSize` can only select a page, call `ToolbarScan.perform` (scan, stop, find or reload for every page) or `SpaceLensModel.choose`, and size the window. None of these paths reaches `clean`, `emptyTrash`, `freeSpaceNow`, `run(command)` or `deleteDevice`/`deleteRuntime`. Trash and History have no toolbar scan.
- **Main actor.** Scans, cleans, put-backs, history reads, simulator listing and measuring, executable checks, inventory, leftovers, large-file search, the Space Lens walk and tree build, access probe, volume, swap and update fetch all run in `@concurrent` functions, kit actors or `async let` children. The app target uses `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` with approachable concurrency, and every app-side `nonisolated` async helper that does work is marked `@concurrent`. The remaining main-actor AppKit calls (icons, `urlForApplication`, `runningApplications`) are on the approved list and cached where it matters.
- **Cancellation and stuck state.** Smart Clean Stop ends the `AsyncStream` loop and lands in `.results` with `scanWasPartial`. Large Files Stop returns a partial report, not an error, so rows are kept. Space Lens uses a generation token, `cancel()` returns to idle, and `partial` is only set on cancel (verified in `StopControl`). `CategoryModel` keeps the previous totals on cancel. Overview, System Data, Trash and History refreshes drop cancelled results and reload on the next appearance. Clean progress readers are finished and awaited before the final state is set, so no spinner is left on. Update cancel returns to `.idle` and failure to `.failed`, and both re-enable Install.
- **Update flow.** The ephemeral session sends no cookies or cache and has a 10 s timeout. Only https github.com release pages are accepted, and assets must each appear exactly once and match the allow-list. A failed or cancelled check never shows a stale "up to date"; a cancelled check does not count toward the daily limit. Dismiss hides the banner per build and is persisted. `install()` refuses a second start (`installTask == nil`), and late stage callbacks cannot overwrite `.ready`/`.installing`. A relaunch failure is reported in plain words. Leftover cleanup trashes only `.TruongCleaner-old-<uuid>.app` folders with our bundle ID.
- **Settings persistence.** Delete mode, auto-check, disabled rules (JSON string), project folders, Large Files folders, onboarding, the update last-checked date and the dismissed build are all written on change and read back with safe defaults. An unreadable `exclusions.json` blocks scans and cleans (`loadedExclusions() == nil`) and is never overwritten without "Start a New List". Clean paths re-read exclusions at clean time.
- **Honest numbers and wording.** Estimates say "about" and private bytes say "at least". Unknown sizes show "Unknown" and never 0 (`SizeText`, simulator sizes, Trash with denied access, Applications `isPartial`). Result sheets keep moved and deleted counts apart and show the measured free-space change next to the estimate. Free Space Now dialogs say they also cover earlier cleans. Space Lens notes that APFS clones are counted in each place.
- **Gate inputs.** Smart Clean, Developer and Applications use `CompositeOwnerProvider` (NSWorkspace, then process name). Trash Empty uses process name only, so a bundle-ID owner counts as unknown and the item is kept. Simulator delete is re-checked in the kit (current `simctl` list, `Shutdown` state).
- **Availability.** I found no API newer than macOS 26: Liquid Glass (`glassEffect`, `GlassEffectContainer`, `.glassProminent`) is 26, and `Tab`, `onKeyPress`, `quickLookPreview`, `selectionDisabled`, `inspector` and `openSettings` are older. All SF Symbols in use exist in SF Symbols 7.
- **Accessibility.** Checkboxes, section select-all, size cells (spoken units), header groups, progress views, table actions, Space Lens list actions (the chart is hidden with a pointer to the list), Reduce Transparency fallbacks (`FloatingGlass`, `ProminentActionButton`, `CleanBar`) and Reduce Motion (`StorageBar`, sunburst, disclosure) all have labels or alternatives.
- **Retain cycles.** Tasks in the long-lived models capture `self` only for a bounded run. `UpdateChecker`, `CategoryModel` and `SpaceLensModel` use `[weak self]`. No model stores a closure that captures itself.
